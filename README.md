# Legacy Goods | Pakistani Clothing

Legacy Goods is a **Pakistani clothing brand preview website**.

## What's included

- Responsive desktop and Android-friendly storefront
- Women's unstitched outfits, women's ready-to-wear, men's kurtas, kidswear, dupattas
- Eight fictional example products with PKR prices and illustrated placeholders
- Search, category filters, sorting, size selector, local demo cart, and demonstration order summaries
- One self-contained index.html file: no build step or dependencies

**Important: preview only.** This is not a functioning online shop. No real orders or payments are accepted. Products, prices, sizes and stock are examples only. Contact/address information entered into the demonstration checkout is not transmitted or persisted; only non-identifying demo order summaries are stored on this browser.

## Publish the development preview with GitHub Pages

Repository: https://github.com/legacygoodsdev/Legacy-Goods-Website-2

1. Open https://github.com/legacygoodsdev/Legacy-Goods-Website-2/settings/pages while signed in as the owner.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**.
4. Press **Save**.
5. GitHub Pages will publish the site's index.html at the repository's project Pages URL:

   https://legacygoodsdev.github.io/Legacy-Goods-Website-2/

6. After deployment, GitHub will show a **Visit site** link in the Pages settings. The URL above is the expected address, not confirmation that deployment is complete.

Updates to the main branch are published automatically when using that branch as the publishing source.

**GitHub Pages hosting limitations:** GitHub prohibits using Pages as a free web host to run a live e-commerce business. This site is a static development/portfolio preview and does not handle real transactions. For a real commercial store, move to hosting whose terms permit ecommerce.

Official documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
